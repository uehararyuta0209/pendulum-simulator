# pendulum-simulator
    物理シミュレーターを実装す
    振り子の長さ、初期角度、観察時間を変化させて
    そのグラフを作成する
# 使い方
    1. リポジトリをクローンする
    2. ライブラリをインストールする
        pip install -r requirements.txt
    3. サーバーを起動する
        flask run
    4. ブラウザで開く
        http://127.0.0.1:5000 をURLに張り付けて開く
# 技術スタック
    python, flask, numpy, scipy, matplotlib
